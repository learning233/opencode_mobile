# OpenCode Mobile 0.10.0 Release Notes / 版本更新说明

## 🇨🇳 中文更新说明

### 🌟 新增功能
1. **点击 Read 卡片支持打开文件**：点击工具调用的 Read 文件卡片即可直接打开并预览对应文件。
2. **Git 分支与未提交文件显示**：支持查看当前 Git 分支信息及未提交文件状态。
3. **项目列表滑动隐藏**：在项目列表中支持通过滑动手势隐藏项目。
4. **文件与代码搜索功能**：支持在项目中快速搜索文件与代码内容。

### ⚡ 缓存与性能优化
- **增加缓存功能**：引入会话历史 SWR 缓存（实现毫秒级秒开）、图片与语法高亮等多级缓存。
- **多项性能优化**：优化流式渲染通道、增加后台 Isolate 异步解码、交互防抖节流以及内存级联释放。

> 💡 **致谢与声明**：感谢 GLM 送的 token，以上大部分由 GLM-5.3-Flash 贡献。并未人工测试。

## 🇬🇧 English Release Notes

### 🌟 New Features
1. **Direct File Opening from Read Cards**: Tapping a "Read" tool card now directly opens and previews the referenced file.
2. **Git Branch & Uncommitted Files Display**: Shows current Git branch info and uncommitted/modified file indicators.
3. **Swipe to Hide Projects**: Projects in the project list can now be hidden via swipe gestures.
4. **File and Code Search**: Fast searching across project files and code content.

### ⚡ Caching & Performance Optimizations
- **Caching Capabilities**: Introduced SWR session history caching for near-instant opening, alongside multi-level media and syntax highlighting caching.
- **Performance Optimizations**: Optimized streaming rendering channels, offloaded heavy decoding to background Isolates, and added input/request throttling and memory cleanup.

> 💡 **Acknowledgment & Note**: Thanks to GLM for the complimentary tokens. Most of the changes above were contributed by GLM-5.3-Flash and have not been manually tested.
