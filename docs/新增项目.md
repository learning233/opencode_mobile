# 📂 新增项目操作指南

<p align="right">
  <a href="./ADD_PROJECT_EN.md">English</a> | <b>简体中文</b>
</p>

本文档说明如何在 OpenCode Mobile 中新增本地项目或导入已有的 GitHub 项目。

---

## 1. 🆕 新建本地项目

如果您需要从头开始创建一个全新的本地项目：

1. **创建项目目录**  
   手动创建项目文件夹，或借助 AI 工具生成基础项目结构。

2. **初始化 Git 仓库**  
   进入项目根目录，执行以下命令完成初始化提交（以便追踪变动）：
   ```bash
   git init && git add . && git commit -m "init"
   ```

3. **在应用中添加项目**  
   打开 **OpenCode Mobile** 应用，点击“添加项目”并选择该本地项目文件夹。

---

## 2. 🐙 导入 GitHub 现有项目

如果您需要添加已存在于 GitHub 的项目：

1. **拉取项目至本地**  
   使用 Git 将远程仓库 Clone 到本地：
   ```bash
   git clone <项目仓库地址>
   ```

2. **在应用中添加项目**  
   打开 **OpenCode Mobile** 应用，点击“添加项目”并选择拉取到本地的项目文件夹。
