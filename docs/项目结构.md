# 项目结构

本文档描述 opencode_mobile 仓库的目录组织与各部分职责，帮助快速定位代码。子系统细节见 `docs/` 下对应专题文档。

## 概述

`opencode_app` 是 opencode 的 Flutter 客户端（Android / iOS / Web），通过 Basic Auth 连接远程 `opencode serve` 后端。技术栈：

- **状态管理 / 路由**：GetX（控制器在 `lib/bindings.dart` 注册为 permanent，SSE 长连接依赖其常驻）
- **网络**：Dio（HTTP）+ 自实现 SSE 流式 + PTY WebSocket
- **Rust 核心**：flutter_rust_bridge 2.12.0，负责语音输入（SenseVoice ASR + Silero VAD + onnxruntime）

## 顶层目录

```text
opencode_mobile/
├── lib/                  # Dart 主代码（下文详述）
├── rust/                 # FRB Rust 核心：ASR / VAD / 音频处理

```

## lib/ —— Dart 主代码

### 入口与骨架

| 文件 | 职责 |
|---|---|
| `main.dart` | 入口：`AppLogger.init` → `Global.init` → runApp |
| `app.dart` | MaterialApp / 主题 / 翻译 / builder 配置 |
| `init.dart` | `Global`：全局初始化、加载 `AppSettingsStore` 设置、全局 Rx 状态 |
| `bindings.dart` | GetX 控制器注册（permanent，勿改为临时） |
| `routes.dart` | `AppRoutes`：全部 GetPage 路由表 |

### api/ —— HTTP / SSE 客户端

| 文件 | 职责 |
|---|---|
| `opencode_client.dart` | `OpenCodeClient`：Dio 单例，Basic Auth，401/403 置全局 `unauthorized` 标记 |
| `sidecar_manager.dart` | `SidecarManager`：连接管理，健康检查（5s 超时、至多 3 次、401 快速失败），`updateConnection` 内置 generation + CancelToken 串行化 |
| `sse_client.dart` | `SseClient`：SSE 长连接，独立的 `isCredentialFailed` 状态 |
| `endpoints.dart` | `ApiEndpoints`：端点清单。**混用 v1（无 `/api` 前缀）与 v2（`/api/...`）两套端点，别随意迁移** |
| `mcp_registry_client.dart` | `McpRegistryClient`：MCP registry 查询 |
| `models/` | API 数据模型（DTO）：`session.dart`、`message.dart`、`event.dart`、`permission.dart`、`project.dart`、`file_*`、`vcs_*`、`tool_diff_parser.dart` 等 |

注意：`lib/api/models/` 是后端 DTO，`lib/models/` 是本地 UI 状态模型，两者不同。

### controllers/ —— GetX 控制器

| 文件 | 职责 |
|---|---|
| `project_controller.dart` | 项目列表 / 当前项目 / 打开会话页签（`openedSessionIds` 只在用户主动操作时持久化） |
| `session_controller.dart` | 会话消息、SSE 事件流式接管、权限与提问处理（含 WidgetsBindingObserver 生命周期） |
| `pty_controller.dart` | PTY WebSocket 终端（`PtySession`） |
| `voice_input_controller.dart` | 语音输入状态机，桥接 Rust ASR/VAD |
| `vcs_controller.dart` | Git 分支 / diff 查看 |
| `file_search_controller.dart` | 文件搜索 |
| `settings_controller.dart` | 服务端配置（providers/models/agent 等） |
| `tablet_tool_controller.dart` | 平板双栏工具面板状态 |

### 其他

| 目录 / 文件 | 职责 |
|---|---|
| `models/` | 本地 UI 状态模型：`session_runtime_state`、`browser_tab`、`opened_file`、`quick_phrase`、`model_info` |
| `services/` | `app_feedback_service.dart`（前台提示音，SoundPool 低延迟通道，勿改回 MediaPlayer）、`voice_input_service.dart`（录音 + 调用 Rust） |
| `utils/` | 主题、翻译（`translations.dart`）、diff 渲染/路径、图片压缩与缓存、tool_call 检测、错误格式化、`app_settings_store.dart`（SharedPreferences 持久化）等 |

## rust/ —— FRB Rust 核心

```text
rust/src/
├── api/          # 暴露给 Dart 的接口：simple / online / common
├── models/       # 模型封装：sense_voice（ASR）、vad（Silero VAD）
├── process/      # audio_processor（重采样等）、voice_text
└── online/       # 在线识别相关
```

- `Cargo.toml` 锁定 `flutter_rust_bridge = "=2.12.0"`（与 pubspec 一致）
- 修改 `rust/src/api/*.rs` 后必须执行 `flutter_rust_bridge_codegen generate` 重新生成桥接代码
